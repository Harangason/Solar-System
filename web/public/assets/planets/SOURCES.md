# Planet texture sources

The eight local JPEG textures in this directory were downloaded from the
NASA/JPL Solar System Simulator texture-map database:

- Mercury: `https://space.jpl.nasa.gov/tmaps/pix/mer0muu2.jpg`
- Venus: `https://space.jpl.nasa.gov/tmaps/pix/ven0ajj2.jpg`
- Earth: `https://space.jpl.nasa.gov/tmaps/pix/ear0xuu2.jpg`
- Mars: `https://space.jpl.nasa.gov/tmaps/pix/mar0kuu2.jpg`
- Jupiter: `https://space.jpl.nasa.gov/tmaps/pix/jup0vss1.jpg`
- Saturn: `https://space.jpl.nasa.gov/tmaps/pix/sat0fds1.jpg`
- Uranus: `https://space.jpl.nasa.gov/tmaps/pix/ura0fss1.jpg`
- Neptune: `https://space.jpl.nasa.gov/tmaps/pix/nep0fds1.jpg`

Catalogue and provenance: `https://space.jpl.nasa.gov/tmaps/`

The JPL catalogue notes that several rocky-body maps are spacecraft mosaics.
The gas-giant maps are representative visual textures because their visible
atmospheres change over time. These assets are visualisation material and are
not used for scientific surface analysis.
